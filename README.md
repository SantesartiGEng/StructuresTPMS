# StructuresTPMS
An algorithm and a MATLAB script to optimize mechanical properties of TPMS structures (e.g. stiffness). Structures are generated through TPMS Designer toolbox (ref. Jones, A., Leary, M., Bateman, S., &amp; Easton, M. 2021. TPMS designer: A tool for generating and analyzing triply periodic minimal surfaces. Software Impacts, 10, 100167.)
